# Draft 4 referee review and verification package

This eight-page report reviews Luke Martin's supplied eleven-page Draft 4 as
standalone mathematics. Recommendation: minor revision, now principally
reproducibility documentation and editorial precision. Previous mathematical
requests are closed. An optional third-moment proof sharpens the uniform-flux
classification to exactly thirteen distinct spectra.

## Read and compile

The report is supplied as PDF and editable LaTeX source. Compile twice:

    pdflatex Draft4_Referee_Report.tex
    pdflatex Draft4_Referee_Report.tex

No external bibliography or figure assets are required.

## Repeat the independent checks

Install requirements.txt in a Python environment, then run:

    python3 run_all.py

Do not use Python -O: the checkers use assertions. The runner propagates failure.
The five earlier checkers are reused verbatim from the previous review and from
the tagged repository; the runner was extended with check_flux_moments.py.
The new checker counts length-three closed walks exactly modulo z^24-1 and
checks numerical moment residuals. The proof of exactly thirteen spectra uses
strict monotonicity of cosine, as given in the report, not floating-point gaps.

verification_results.json, deeper_results.json, supplement_results.json,
moment_results.json and magnetic_sweep.csv are regenerated by this command.
Numerical projector weights and the general-charge eigenvalues are explicitly
numerical; polynomial, Gram, rotation and supplementary algebra checks are exact.
The deeper checker contains an earlier optional weighted extension, which is
not an outstanding requirement on the paper.
